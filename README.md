# Komentář k zákonu č. 215/2004 Sb., o úpravě některých vztahů v oblasti veřejné podpory a o změně zákona o podpoře výzkumu a vývoje

Konsolidované znění: dokument e-Sbírky `SB-2004-00215_2025-04-03`.
